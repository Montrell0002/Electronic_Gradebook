# Electronic Gradebook System

## Description
The Electronic Gradebook System is a Java-based application designed for teachers to manage student grades efficiently through a secure login system. Built using Java, MySQL, and NetBeans, the system allows teachers to add, delete, update, sort, and analyze student grade records. Teachers can also check for the lowest grades, calculate final grades, and generate report cards.

## Technologies Used
- Java
- MySQL
- NetBeans IDE
- JDBC

## Features
- Secure user login system
- Add student grade records
- Delete student records
- Update/alter existing grades
- Sort student grades
- Check for lowest grades
- Calculate and view final grades
- Generate student report cards
- Store and retrieve data using MySQL database

## How It Works
1. User logs into the system using a username and password.
2. Teacher adds student information and grades.
3. Records are securely stored in the MySQL database.
4. Teacher can edit, delete, or sort grade records.
5. The system automatically calculates final grades.
6. Teachers can generate and review report cards for students.

## Purpose of the Project
This project was created to provide teachers with a digital solution for organizing and managing student grades. The system improves efficiency, reduces manual errors, and simplifies grade tracking and report card generation.

## Database Functionality
The MySQL database stores:
- User login credentials
- Student information
- Assignment/test grades
- Final grades
- Report card data
